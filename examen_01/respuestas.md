# Definicion de las preguntas

1.- Define clase

1.1.- Es un dato que tu diseñas para agrupar datos (tambien llamada atributos) y funciones (tambien llamda métodos).

2.- Define encapsulamiento 

2.2.- Es como un mecanismo para proteger los datos de una clase permitiendo que solo se pueda acceder a ellos a traves de funciones especificas y segueras que tu mismo defines.

3.- Define Constructor

3.3.- Es un método especial de una clase que se ejecuta automáticamente en el momento exacto en que creas un objeto, este no tiene tipo de retorno porque su única función es agrupar y asignar los valores iniciales a los atributos.
